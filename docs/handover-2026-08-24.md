## Hard-won invariants (all in architecture §7, don't relearn them)

1. **nDB find() returns no live references** — long-lived holders refresh at read points (`runner.refresh()`).
2. **Message order is contractual** — in-flight assistant persists at its RESERVED idx (`insertConversationMessageAt`); queued sends append after. Assistant-final payload = prefill → thinking-mode 400.
3. **Aborted runs persist content only** (truncated reasoning = malformed thinking block); API view drops `reasoning_content` without `thinking_signature`.
